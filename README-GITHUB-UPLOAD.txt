HOLY FAMILY YOUTH GROUP — GITHUB UPLOAD PACKAGE

All files are at the same level. You do not need to create folders in GitHub.

1. Extract this ZIP on your computer.
2. Open your GitHub repository.
3. Click Add file -> Upload files.
4. Open the extracted folder and select ALL files inside it (Ctrl+A).
5. Drag the selected files into GitHub's upload area.
6. Commit changes to the main branch.

Upload the files inside this folder, NOT the ZIP itself.
Keep every file together in the repository root.
index.html must remain at the top level.
The official logo is included as holy-family-youth-group-logo.jpg.

This is the frontend foundation only. Authentication, database and live modules come later.
